# The starter kit, kept safe

`hillclimb-kit.bundle` is the starter kit's whole local git history (no repository exists for it
yet, at Aaron's request). Restore it with:

```sh
git clone kit/hillclimb-kit.bundle hillclimb-kit
```

It is refreshed whenever the kit's local history moves. The kit's own README says how to install
and check it (pnpm 12.18.0, Node 24.22.2).
