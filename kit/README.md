# The starter kit, kept safe

`hillclimb-kit.bundle` is the starter kit's whole local git history (no repository exists for it
yet, at Aaron's request). Restore it with:

```sh
git clone kit/hillclimb-kit.bundle hillclimb-kit
```

It is refreshed whenever the kit's local history moves. The kit's own README says how to install
and check it (pnpm 12.18.0, Node 24.22.2).

## The swarmD rebuild's design, kept for reference

`swarmd-next-design.bundle` is the abandoned swarmD rebuild (Aaron, 9 November 2026: "We're going to abandon the
swarmd rebuild. We're just going to use swarmd as it is today, and fix it as needed."). It holds the idea, 48
operations, the records, the evals, five spikes on pi-durable and a goal prompt, made by the kit's own skills. It is
kept as the starting point for mapping today's swarmD into a book (its MAP-SWARMD.md says how). Restore it with `git clone kit/swarmd-next-design.bundle`.
