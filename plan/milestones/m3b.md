## What it delivers

A dedicated machine on the existing AWS cloud that hosts worlds: one Frappe bench for every company's site, a small service and a chain per world, one catch-all route so a new company or world needs no proxy change, and nightly backups. A world there is created by one command and opened in a browser.

## Why it is here

None of this should live on a laptop. The machine is also where the thin line has to run for the goal to be met.

## How we know it is done

A shared world on the machine runs the thin line, and a person watches a company's screens while it happens.

## What it needs from Aaron

The AWS sign-in on this Mac, the subdomain, and four DNS records at Namecheap.
