## What
Every operation gets at least one example: the command as typed and what it prints, checked by the build against what the operation is declared to return. Where the spikes have run a command for real, the example is the real output.
## Why
The experience of the CLI cannot be judged from a list of fields. Examples are how Aaron and agents see what a command is like before it is built.
## Done when
- The gap count for operations with no example is zero, or each remaining one has a recorded reason.
- The portal's operation pages show the examples as terminal sessions.
