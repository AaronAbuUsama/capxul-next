# Accounts schema inspection

`run.sh --list` lists admissions, personal Safe and referral shape checks. The shared read-only selected-world guard is Access's `service.ts`: running receipt first, private world config, actual fixture, matching Core code/readiness and restricted Postgres identity/epoch. There is no migration, admin fallback or invented actor setup in this runner.

All three declarations are **near-only**. Fields/types/nullability, key/index semantics, forced RLS and each literal-set field's validated enum constraint are inspected independently, but non-enum row constraints/migration origin and the complete authorized writer matrix are not proved. Tenancy, atomicity and transition claims remain unbound until the same-attempt public journey exists; historical skeleton or component controls earn no acceptance credit. Parked individual referral/waitlist operations are not reopened.
