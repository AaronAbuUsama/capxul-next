# Archive: the as-is book

The as-is book described the old Capxul system (`Xelmar-tech/infrastructure`, branch
`integration/factory`) in the same records as the design book. It was closed on 8 November 2026
(see `docs/mission/remaining-work.md`): the old system is a reference for behaviour, not a
baseline, and the target book (`books/target/`) no longer needs it.

These files are kept as evidence only. They are outside every typecheck, and their relative
imports point at the folder they were written in (`books/as-is/`), so they do not compile here.
Target records' `was` fields cite them by their path in this folder. The reviewed lane is
payments, written up in `docs/as-is/payments.md` with its keep list (K1 to K18) and findings.
